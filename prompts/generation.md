# Template de génération

Utiliser ce template pour les rendus d'une couche ou d'une zone uniquement. La
géographie est fournie par les images de référence, couches et masques : elle ne
doit pas être réinventée.

```text
Référence géographique : {{reference_image}}
Couche concernée : {{target_layer}}
Masque à respecter : {{mask}}
Niveau de liberté artistique : {{artistic_freedom}}

Contraintes de conservation :
{{preservation_constraints}}

Direction artistique :
{{requested_style}}

Ne pas déplacer, ajouter, supprimer ou déformer les éléments géographiques
contraints. Ne produire aucun texte, nom de lieu ou lettrage définitif.
```
